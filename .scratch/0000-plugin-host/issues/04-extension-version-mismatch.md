# 0000-04 — 扩展版本不兼容

Status: ready-for-agent

**What to build:** 工作台升级后，在插件管理页定位具体失配的扩展，同时继续使用新版工作台与兼容扩展。

**Blocked by:** [0000-02 界面扩展点](02-view-extensions.md)、[0000-03 本地目录热更新](03-reload-local-plugin.md)

## 验收条件

- [ ] 让同一插件提供两个扩展，更新提供方，使其中一个扩展点版本不兼容。
- [ ] 新版工作台正常打开，兼容扩展能执行，失配扩展从对应位置撤下。
- [ ] 管理页列出受影响的扩展点、要求的版本及实际版本；恢复兼容版本后按启用偏好重新挂载一次。
