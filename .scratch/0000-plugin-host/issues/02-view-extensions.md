# 0000-02 — 界面扩展点

Status: ready-for-agent

**What to build:** 独立插件根据功能页公开的声明添加菜单项或页签，并能随提供方的生命周期撤下和恢复。

**Blocked by:** [0000-01 单入口与插件管理](01-desktop-entry.md)

## 验收条件

- [x] 样例页声明界面及扩展点的稳定标识、版本、接收内容和上下文，独立插件声明目标与兼容版本。
- [x] 启用扩展后，从样例页使用新增操作，获得与页面当前选中项对应的结果。
- [x] 停用提供方后扩展撤下；再次启用时，按原启用偏好恢复，菜单或页签只出现一次。

实施检查：独立消费插件先启动，提供方连续两次恢复后各有一个可执行操作。
