# 0000-01 — 单入口与插件管理

Status: ready-for-agent

**What to build:** 从同一个桌面入口打开工具，在插件管理页启停一个普通 F# 功能页，并能随时回到管理页。

**Blocked by:** 无，可直接开始。

## 验收条件

- [x] 在已装相应 .NET 运行时的 Windows x64 上启动框架依赖发布产物，F# 与 Avalonia.FuncUI 界面显示布局、菜单和管理页。
- [x] 核心管理页和普通样例页共用界面注册方式。管理页能区分固定加载的核心插件和可启停的普通插件。
- [x] 通过 CordiSharp 管理普通插件的生命周期。连续两轮启用、停用后，启用时只有一个可用入口，停用时入口撤下，核心菜单和管理页仍可使用。

实施检查：Windows x64 框架依赖发布成功，CordiSharp 两轮启停测试通过。桌面操作留待统一验收。
