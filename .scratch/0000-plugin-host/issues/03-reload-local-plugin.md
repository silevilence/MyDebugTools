# 0000-03 — 本地目录热更新

Status: ready-for-agent

**What to build:** 选一次仓库外的公司插件编译目录，之后把新版编译到原目录，在工具内手动重载。

**Blocked by:** [0000-01 单入口与插件管理](01-desktop-entry.md)

## 验收条件

- [x] 启用旧版插件，在独立页面留下输入，插件运行期间能完成同目录覆盖编译。
- [x] 点击重新加载后，操作返回新版结果，每次操作只响应一次，独立页面的输入仍可用。
- [x] 使用有私有依赖的样例反复重载，核对各自的依赖行为和卸载诊断，确认旧版本可以回收。

实施检查：已在两个仓库外目录载入同名私有 DLL，在启用期间两次覆盖编译并回收旧加载上下文；采集停止顺序的独立测试通过。
