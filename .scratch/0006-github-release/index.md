## 本地验收

- 在同一台 Windows x64 沙盒中从开始菜单启动 1.0.0，覆盖升级后从同一快捷方式启动 1.0.10。原插件目录登记和启用状态、保存的接口和 HTTP 200 日志仍可查看。
- 从安装后的 DLL 工作台分别调用 x86、x64 样例的 add(5, 7)，两次均返回 12。模拟缺少 x86 运行时时，目标页提示所需位数。模拟缺少 x64 运行时时，安装程序分别说明宿主与目标的要求。
- 发布判断测试覆盖标签、说明、版本冲突、部分上传、公开资产冲突和较旧版本补发。安装包版本与宿主不匹配时，本机构建明确报错，未生成安装包。
