# 0001-04 — 读写复杂参数

Status: ready-for-agent

**What to build:** 填写字符串、缓冲区或普通 C 结构体，调用函数后检查输出参数及各字段的实际值。

**Blocked by:** [0001-03 跨位数连续调用](03-invoke-across-architectures.md)

## 验收条件

- [ ] 用指定编码传入字符串，以已知长度缓冲区接收结果，返回的字节及长度与样例一致。
- [ ] 通过输出指针读回已知值；分别在 x86/x64 样例中传入用户描述的结构体，核对目标收到的字段、写回的字段和界面显示值。
- [ ] 遇到缺少缓冲区长度、布局信息或暂不支持的签名时，指出具体参数和原因，保留已填写的值。
