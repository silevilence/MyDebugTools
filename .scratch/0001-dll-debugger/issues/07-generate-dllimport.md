# 0001-07 — 生成 DllImport 代码

Status: ready-for-agent

**What to build:** 用已确认的签名生成 C# 和 F# 的 DllImport 声明与调用示例，可从工作台复制或批量导出。

**Blocked by:** [0001-04 读写复杂参数](04-complex-arguments.md)

## 验收条件

- [ ] 选一个函数，分别复制两种语言的调用示例并编译运行，返回值和输出参数与同架构工作台结果一致。
- [ ] 多选标量函数和带结构体的函数，分别复制及导出所选声明，含所需的类型定义；未勾选的函数不在结果中。
- [ ] 混选签名不完整或当前形式无法表达的入口时，逐项说明原因，可生成部分仍可编译。
