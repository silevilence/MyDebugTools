# 0001-03 — 跨位数连续调用

Status: ready-for-agent

**What to build:** 从工作台调用简单函数，在同一调试会话沿用 DLL 状态和句柄，并能重新开始。

**Blocked by:** [0001-02 录入并复用签名](02-confirm-signature.md)

## 验收条件

- [x] 同一入口分别调用 x86/x64 样例的整数、浮点函数，自动选择匹配的后台进程，返回值符合预期。缺少对应运行时时指出具体架构。
- [x] 依次调用打开、使用、关闭句柄的函数，结果体现同一会话的状态。手动重新开始后，测试计数器回到初始值，旧句柄失效。
- [x] 签名缺项时显示原因。后台异常退出或调用超时后主界面保留输入，重新开始会话后能再次完成正常调用。

实施检查：x86/x64 后台均通过标量、序号、句柄连续调用、超时及重启检查。
