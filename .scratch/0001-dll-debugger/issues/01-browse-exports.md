# 0001-01 — 打开 DLL 查看导出

Status: ready-for-agent

**What to build:** 在 DLL 工作台选择一个原生 DLL，即可按文件内容浏览架构和导出。

**Blocked by:** [0000-01 单入口与插件管理](../../0000-plugin-host/issues/01-desktop-entry.md)

## 验收条件

- [ ] 在同一个入口打开本地 x86 和 x64 样例，分别核对机器架构、具名导出的序号和相对地址。
- [ ] 仅按序号导出的条目可见；转发导出显示转发目标，数据导出和无法判定的条目标明性质或不确定性。
- [ ] 静态浏览无需执行 DLL 初始化；仅有 DLL 时仍可浏览，未知的函数参数和返回类型可辨认。
