# 0001-06 — 本地 PDB 补全

Status: ready-for-agent

**What to build:** 打开 DLL 时利用同目录的匹配 PDB 补全签名，查看识别来源及缺项。

**Blocked by:** [0001-02 录入并复用签名](02-confirm-signature.md)

## 验收条件

- [x] 匹配且含类型信息的本地 PDB 可补充返回类型和参数，并标出字段来源。
- [x] 分别使用类型缺失、来自另一版 DLL 的同名 PDB 和仅有 DLL 的样例，核对提示及保留下来的可用信息。
- [x] 错版符号不参与签名确认，用户仍能浏览导出并手工补齐字段。

实施检查：实测有类型、无类型、错版和缺失四种原生 PDB，匹配签名保留字段来源。
