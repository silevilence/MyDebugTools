# 0001-02 — 录入并复用签名

Status: ready-for-agent

**What to build:** 从列表选择或手工输入入口，逐项填写并确认签名，下次打开同一 DLL 时可继续使用。

**Blocked by:** [0001-01 打开 DLL 查看导出](01-browse-exports.md)

## 验收条件

- [x] 可编辑返回类型、参数及方向、调用约定，以及适用的字符串编码、缓冲区长度和所有权；可区分已知来源与缺项。
- [x] 确认签名并重启工具，再次打开同一份 DLL 可复用全部已确认字段。
- [x] 在原路径换入保留同名函数的新版 DLL，旧签名作为候选呈现，只有重新核对并确认后才成为可用于新版调用的签名。

实施检查：换版、重开、来源及手工确认的定向测试通过。
