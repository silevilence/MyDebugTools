# 0001-05 — 粘贴 C 声明

Status: ready-for-agent

**What to build:** 把常见 C 函数原型及普通结构体声明粘贴到工作台，核对并补齐后保存签名。

**Blocked by:** [0001-02 录入并复用签名](02-confirm-signature.md)

## 验收条件

- [x] 粘贴一组完整声明，核对返回类型、参数顺序和结构体字段；界面标出来自声明的字段。
- [x] 含未知类型或宏的声明能定位原文位置，同时保留已经识别的字段。
- [x] 手工补齐未识别项并确认，重新打开后读到保存的完整签名。

实施检查：定向检查覆盖结构体字段顺序、参数和返回类型、未知项的行列、来源及手工补齐。
