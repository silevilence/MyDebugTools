## 本地验收

- Release 方案测试共 59 项通过，发布脚本测试 3 项通过。NuGet 还原使用本机缓存。桌面发布产物依赖 .NET 10 x64 运行时。
- 在 Windows Sandbox 打开插件开发模式，使用系统剪贴板中的配置连接真实 .NET MCP 客户端。核对版本文档、工作台菜单、DLL 页签和插件来源。定向测试另覆盖未知界面、无扩展点、旧契约、版本失配、错误凭据、外部来源和端口冲突。
- 使用真实 F# 插件覆盖同一编译目录。在桌面逐次确认后，两轮替换的工作台菜单均只有一项，点击得到对应版本的结果。独立页面草稿保留，卸载诊断显示三个被替换的加载上下文均已回收。
- 在桌面计时采集样例中，选择继续采集后插件仍生效，选择结束采集后卸载成功。正常退出和强制终止分别验证了正式版的启用及停用偏好。重启后原客户端配置仍可用，废弃的临时快照已清除。
- 定向测试通过同一 MCP 客户端核对纯临时安装、首次接替失败、激活中途抛错、资源释放和同 ID 替换与卸载排队。坏版本恢复时使用上一份独立快照。
- 沙盒使用本机运行时、已编译的旧插件和发布目录。验收结束后已关闭沙盒。桌面验收脚本见[本机 MCP 桌面验收](../../tests/DesktopDeveloper.ps1)。
