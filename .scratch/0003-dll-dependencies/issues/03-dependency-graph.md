# 0003-03 — 切换依赖图

Status: ready-for-agent

**What to build:** 在当前文件的依赖树与依赖图之间切换，使同一解析结果中的路径、共享关系和环均可核对。

**Blocked by:** [0003-01 当前 DLL 的依赖树](01-dependency-tree.md)

## 验收条件

- [x] 在含共享依赖和环的样例中切换视图，核对节点、引用关系、导入类型和缺失状态一致。
- [x] 用两份命中路径及下级依赖不同的解析结果更新当前文件视图，树与图同步切换至对应结果。
- [x] 与搜索目录功能集成时，调换目录顺序后在两种视图核对实际路径和新的下级依赖。

实施检查：缺失、命中 A、命中 B 三种结果分别核对图中每条边与树中原始导入对象一致，共享模块只生成一个图节点。界面切换复用同一份解析结果。
