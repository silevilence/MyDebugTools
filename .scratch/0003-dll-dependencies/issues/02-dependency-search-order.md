# 0003-02 — 调整目录并解释命中结果

Status: ready-for-agent

**What to build:** 在依赖页签添加并重排搜索目录，查看每次实际命中的文件、下级依赖和未解析原因。

**Blocked by:** [0003-01 当前 DLL 的依赖树](01-dependency-tree.md)

## 验收条件

- [ ] 初始缺失的依赖在添加含相应文件的目录后立即解析，显示目标架构和完整路径。
- [ ] 加入两个含同名、同架构 DLL 但下级依赖不同的目录，调换顺序后核对新的命中路径与下级依赖。
- [ ] 对架构不匹配、缺失文件和 API Set 样例分别显示原因或解析结果，合约名称与宿主文件可区分。
