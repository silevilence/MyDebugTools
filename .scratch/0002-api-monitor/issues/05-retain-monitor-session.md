# 0002-05 — 监控中的停用与热更新

Status: ready-for-agent

**What to build:** 监控插件停用前让用户决定是否结束当前采集，重载后可以继续查看原会话记录。

**Blocked by:** [0000-03 本地目录热更新](../../0000-plugin-host/issues/03-reload-local-plugin.md)、[0002-02 启动目标并核对调用](02-monitor-launched-program.md)

## 验收条件

- [ ] 停用提示显示当前目标进程。等待选择期间继续采集，选择继续后后续调用进入同一会话。
- [ ] 选择结束监控并停用后采集结束，目标继续工作，插件可以重载。
- [ ] 重载后在原会话中核对更新前一条记录的参数、返回值和栈；退出并重新启动主程序后记录清空。
