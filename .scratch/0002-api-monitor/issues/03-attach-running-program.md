# 0002-03 — 附加已有进程

Status: ready-for-agent

**What to build:** 附加当前用户已经启动的桌面或命令行进程，从采集生效时开始记录，停止后可继续使用目标程序。

**Blocked by:** [0002-02 启动目标并核对调用](02-monitor-launched-program.md)

## 验收条件

- [ ] 在已知调用序列中途附加 x86/x64 样例，核对生效前后的记录边界。覆盖 .NET 程序调用原生 DLL 的场景。
- [ ] 父子进程执行同一函数时，父进程会话只显示父进程的调用；单独附加子进程后可在其会话查看后续记录。
- [ ] 停止采集后原目标继续运行，可完成下一次操作，已停止的会话不再追加调用。
