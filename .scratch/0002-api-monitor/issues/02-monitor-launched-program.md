# 0002-02 — 启动目标并核对调用

Status: ready-for-agent

**What to build:** 从 DLL 勾选函数并启动当前用户的普通测试程序，按次查看本次会话的调用记录。

**Blocked by:** [0001-02 录入并复用签名](../../0001-dll-debugger/issues/02-confirm-signature.md)

## 验收条件

- [ ] 分别启动 x86/x64 可控样例，界面自动匹配目标架构并显示采集生效时间。
- [ ] 生效后让选中的函数以已知参数执行十次，并另行调用未选函数。核对已选调用计数与目标自身记录一致。
- [ ] 展开单次记录，核对线程、入参、返回值、调用栈和耗时；缺少符号的栈帧显示模块与偏移。
