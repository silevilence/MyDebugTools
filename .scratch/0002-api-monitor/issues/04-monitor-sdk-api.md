# 0002-04 — 用内置定义监控和补签名

Status: ready-for-agent

**What to build:** 从内置目录直接选函数查看采集结果，也可在 DLL 工作台用同一份定义补全签名。

**Blocked by:** [0002-01 搜索 Windows API](01-search-windows-api.md)、[0002-02 启动目标并核对调用](02-monitor-launched-program.md)

## 验收条件

- [ ] 同一 API 在两处显示一致的已知类型和来源；在监控页不经文件选择即可选中并验证可控样例的调用。
- [ ] 分别核对完整、部分及不支持条目的事先提示与实际记录；无法解码的字段明确标示。
- [ ] 并发调用能按线程和调用配对；仍在执行、未完整记录及发生采集丢失的样例可在界面分辨。
