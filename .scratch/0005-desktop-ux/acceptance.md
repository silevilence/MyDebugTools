# 桌面工作区发布版验收

2026-11-24 在 Windows 上运行框架依赖的 x64 发布版。每个自动化场景使用独立的本地配置。从首页、菜单、文件选择器、工具页和确认框操作，用进程号区分窗口。系统剪贴板与鼠标测试使用关闭网络和剪贴板重定向的 Windows Sandbox。首次试用记录见[四张任务卡](agent-trials.md)。

| 旅程 | 核对方式与结果 |
| --- | --- |
| A · 开始任务 | 空配置显示 DLL、监控、HTTP 入口。选择依赖直达依赖页。重新打开 HTTP 后找回原 URL。 |
| B · 调试目标 | 用 x86、x64 文件核对宿主和目标位数，并将当前路径带入工作台。在沙盒暂时移开 x86 运行时登记后，界面指出缺少 x86 运行时，静态浏览仍可用。 |
| C · DLL 工作台 | 同路径换版要求重新确认。两种位数均得到 add(5,7) = 12。检查签名草稿、复杂参数、输出与连续调用。三种格式的示例及部分成功的批量生成均通过。系统剪贴板与屏幕上的 LibraryImport 代码一致，保存文件也逐字比对。 |
| D · 依赖 | 两个同名模块目录的搜索顺序会改变实际命中路径。树和图中的普通、延迟、缺失、共享与循环边一致。缺失项可定位到引用方并复制链路。 |
| E · 监控 | x86、x64 样例均实际产生 10 次调用，界面报告 10 次、丢失 0。交互样例分别验证继续采集、结束采集后目标继续运行、重载后查看旧详情与宿主退出清理。 |
| F · HTTP | 与本地服务核对方法、路径、查询、头及正文的实际字节。覆盖空、原始、表单、multipart 和二进制正文，以及 HTTP 204、503、格式化失败、超时、取消和拒绝连接。两次订单和保存定义的默认值可分别核对。 |
| G、J · 插件 | 真实 F# 插件通过 CordiSharp 注册 FuncUI 页面和扩展。开发目录可重复覆盖，更新后显示新版操作。契约版本不匹配时仅撤下受影响项，恢复兼容后可再次操作。旧程序集可回收。 |
| H · 诊断 | 从系统剪贴板读回插件目录、文件、进程、签名、依赖、监控、JSON 及 HTTP 错误。逐项核对时间、版本、动作与原因。合成凭据及私人路径没有随报告带出。占用剪贴板时原文仍可选取，解除占用后能复制当前错误。 |
| I · 尺寸与输入 | 默认 860 × 580 和最小 580 × 400 逻辑尺寸。系统缩放 200%，另用 Windows 进程 DPI 兼容模式验证 96 DPI。分别核对浅色、深色和系统高对比度，关闭系统动画后仍能键入并以 Enter 提交。 |
| K · 外部包 | 通过原生文件选择器加载本地 ZIP，执行 v1，重复导入定位已有行。取消换版仍能执行 v1，确认换版后重启仍执行 v2。取消卸载后仍可用，确认后移除。集成测试另覆盖新版激活失败回滚、文件占用后重试、非法包，以及原 ZIP 和开发目录的哈希。 |
| L · 工作区 | Dock.Avalonia 12.1.0。工具菜单可向四边停靠、合并、隐藏与找回。实际鼠标拖动显示落点，Esc 取消，标签可换序，分隔条可改变宽度。真实外部面板浮动时替换两次，旧程序集均可回收。把保存的浮窗坐标移至所有屏幕之外后重启，浮窗回到可见区域。损坏的布局回退到首页。 |
| M · 连续使用 | 对照请求与响应时原草稿仍在。延迟响应到达后，所选日志、详情与键盘焦点保持。切换函数可以找回原稿，依赖树与图同步选择，监控按函数筛选并显示匹配数。 |

## 回归中修复的问题

- 导出表首次创建列表行时，空的虚拟行曾导致页面中断。修复后，两种位数均可从首页走到真实调用和代码导出。
- 分栏后重新打开有时只换了标签，正文仍停在其他工具。另一次重载把主窗口中的普通页误判成浮窗。修复后，连续三次启停同一工作台都能读到工作台草稿，浮动插件也能回到原位置。
- 布局最初未能写盘，关闭主窗也可能留下恢复出的浮窗。现在从真实退出、重启入口核对恢复结果，并确认测试进程退出。
- 真实拖动时，Esc 曾允许松开鼠标后继续放置。修复后核对了原标签位置、后续换序、分隔条移动和草稿。
- 首次试用时采集选择框有过瞬时 PID 0。现在核对活动目标进程号、已完成会话标题和样例实际调用数。

## 重现与资源

从仓库根目录发布，随后运行相应的桌面场景。常规桌面回归、HTTP 和监控三组各使用自己的进程和测试数据。

```powershell
dotnet publish src/Desktop -c Release --no-restore -o artifacts/0005/final
dotnet test MyDebugTools.slnx --no-restore -m:1
./tests/Desktop.ps1 -Publish artifacts/0005/final
./tests/Desktop.ps1 -Publish artifacts/0005/final -WebApiOnly
./tests/Desktop.ps1 -Publish artifacts/0005/final -MonitorOnly
./tests/Desktop.ps1 -Publish artifacts/0005/final -PackagesOnly
```

真实剪贴板、运行时缺失、鼠标和显示设置在隔离桌面验证。诊断回归可用 `-EchoPortFile` 指向已经启动的本地回显服务端口文件。对应入口为 `-ReportsOnly`、`-UxOnly`、`-PointerOnly` 和 `-AppearanceOnly`。宿主回收和程序重启均从正常退出入口检查。完整解决方案共 54 项，DLL 35 项、宿主 11 项、Web API 8 项。另有发布版桌面场景及三种生成格式的剪贴板检查。

复用了本机的两种位数运行时、DLL/PDB、F# 插件、PowerShell、Python 和 NuGet 缓存。首次接入 Dock 时补齐本地缺少的依赖，沙盒回归直接映射已有资源。离屏恢复采用越界的真实浮窗布局模拟显示器移除。
