# 0005-13 — 从缺失依赖追到引用方

Status: ready-for-agent

**What to build:** 从未解析项找到引用它的模块，切换视图和调整搜索顺序时沿用当前 DLL 和导入关系。

**Blocked by:** 无，可立即开始

对应[桌面体验规格](../spec.md)的验收旅程 D、M。

## 验收条件

- [ ] 本地样例覆盖无导入、缺失、架构不匹配、延迟导入、共享、循环和 API Set。摘要说明静态范围，条目显示原因。
- [ ] 从未解析摘要定位到相关树节点并复制引用链。切换到图时选中相同模块，多个引用方可辨。树与图复用当次解析。
- [ ] 浏览或粘贴两个同名模块目录，调整顺序并核对两种视图的完整命中路径；刷新后仍可找到原来排查的导入。
- [ ] 快速切换目标时，分析状态和结果归属明确。失败时保留可用线索，键盘可查看长路径。
