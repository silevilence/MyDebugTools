# 0005-03 — 用表格管理全部插件

Status: ready-for-agent

**What to build:** 在一张表里辨认插件来源、状态及可做的操作，从对应行管理插件。

**Blocked by:** 无，可立即开始

对应[桌面体验规格](../spec.md)的验收旅程 G、J、I。

## 验收条件

- [x] 表中可按名查找，展示名称、界面或扩展用途、来源、版本、状态、操作。未知版本明确标注。窄窗保留名称、状态和操作，其他字段可从详情读取。
- [x] 关联真实外部 F# 编译目录后定位到对应行。核心插件固定加载，随附普通插件与开发目录可区分。
- [x] 原目录覆盖编译并手动重载两次，核对新版操作各响应一次、其他页面草稿保留，卸载诊断可复制且显示旧程序集回收。
- [x] 采集期间停用或重载时列出受影响目标。继续或关闭对话框后采集继续，确认结束时先停止，再执行用户选的动作。

验收记录见[发布版验收](../acceptance.md)。
