# 0005-10 — 查找导出并保住签名草稿

Status: ready-for-agent

**What to build:** 静态打开 DLL、选中入口并核对签名字段，回来时可以接着编辑同一函数。

**Blocked by:** 无，可立即开始

对应[桌面体验规格](../spec.md)的验收旅程 C、M。

## 验收条件

- [x] 用 x86、x64 本地样例核对目标架构、导出数与 PDB 状态。名称、序号、相对地址、性质按列对齐，可筛选或手动输入入口。
- [x] 返回类型、调用约定、参数行和结构体字段有常驻标签，分别展示来源、未知与待确认项。支持粘贴 C 声明和高级文本，部分识别失败保留可用字段。
- [x] 修改 add 的调用约定，切到另一函数再返回，草稿仍在，状态为待确认。已确认签名按文件身份复用。
- [x] 同路径换版必须重新核对签名。打开文件失败时显示尝试对象与当前活动文件，静态浏览过程不执行目标代码。

验收记录见[发布版验收](../acceptance.md)。
