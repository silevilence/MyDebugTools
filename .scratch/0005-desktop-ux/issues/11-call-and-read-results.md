# 0005-11 — 按签名调用并核对结果

Status: ready-for-agent

**What to build:** 沿已确认签名填写实参、查看返回与输出，并在同一 DLL 调试会话中继续工作。

**Blocked by:** [10](./10-export-signature-drafts.md)

对应[桌面体验规格](../spec.md)的验收旅程 C、M。

## 验收条件

- [x] 分别用 x86、x64 本地样例将 5 与 7 传给 add，得到 12。未确认或缺失的必要信息可从调用位置定位。
- [x] 用已有样例覆盖字符串、结构体、缓冲区和输出参数。按签名录入或编辑 JSON 后，界面能分清返回值和各输出项。
- [x] 连续调用保留会话状态。切换入口后，已有结果仍标明原函数和本次实参。
- [x] 异常、超时或缺运行时时说明原因并保留输入。重新开始会话前说明旧句柄的影响，用户能恢复调试。

验收记录见[发布版验收](../acceptance.md)。
