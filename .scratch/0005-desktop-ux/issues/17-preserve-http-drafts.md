# 0005-17 — 在定义、草稿与请求日志间切换

Status: ready-for-agent

**What to build:** 组织接口定义，保住尚未发送的请求，并从历史找回一次实际发送的值。

**Blocked by:** 无，可立即开始

对应[桌面体验规格](../spec.md)的验收旅程 F、M。

## 验收条件

- [ ] 给临时请求填写 URL，点击新建或打开定义时可取消、保留草稿或明确放弃。返回后可核对原输入和所属接口。
- [ ] 按目录保存和打开定义。本次实参与默认值清楚区分，发送两个不同订单号后重启，日志分别显示实收值，默认值只随主动保存更新。
- [ ] 重开日志时保留所选记录。最多保留最近 100 条，记录被淘汰或清空时给出说明。
- [ ] 空日志时清空操作不可用或隐藏。有数据时确认框说明数量与影响，取消可继续查看，确认只清空请求日志。
