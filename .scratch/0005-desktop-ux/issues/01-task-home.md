# 0005-01 — 从首页开始调试任务

Status: ready-for-agent

**What to build:** 让首次启动的用户从手里的 DLL、程序或 URL 直接进入相应工具。

**Blocked by:** 无，可立即开始

对应[桌面体验规格](../spec.md)的验收旅程 A、I。

## 验收条件

- [ ] 空配置启动时，默认窗口首屏可见查看 DLL 导出或依赖、监控程序调用、发送 HTTP 请求三个入口及各自用途。
- [ ] 普通插件停用时原处说明用途，点击“启用并打开”后直达所选任务。选择依赖时定位到依赖页，而不是只打开工作台。
- [ ] 核心管理入口始终可达，示例明确标识。切换工具再返回，未发送的 URL 和此前选择仍在。
- [ ] 缩至最小窗口，用键盘从首页进入任务并返回，页面标题、当前导航项和焦点均可辨认。
