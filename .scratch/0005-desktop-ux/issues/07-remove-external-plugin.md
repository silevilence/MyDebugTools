# 0005-07 — 卸载外部包与解除目录关联

Status: ready-for-agent

**What to build:** 按来源移除外部插件，执行前看清受影响功能和磁盘范围。

**Blocked by:** [05](./05-load-plugin-zip.md)

对应[桌面体验规格](../spec.md)的验收旅程 G、K。

## 验收条件

- [x] ZIP 行显示卸载及受管位置，开发目录行显示解除关联。核心和随附普通插件均没有删除操作。
- [x] 确认前列出相关菜单、界面及扩展。取消后仍可用；活动采集先由用户决定继续或结束。
- [x] 用本地样例验证确认后相应注册、界面和受管副本移除，重启不再出现。原 ZIP 与编译目录文件哈希一致，其他插件及业务数据保留。
- [x] 文件被占用时说明具体待处理项，解除占用后可重试。反复操作不会扩大删除范围。

验收记录见[发布版验收](../acceptance.md)。
