# 0005-05 — 从 ZIP 加载外部插件

Status: ready-for-agent

**What to build:** 选择收到的本地插件 ZIP，预览后启用，从真实页面使用包内功能。

**Blocked by:** [03](./03-plugin-table.md)

对应[桌面体验规格](../spec.md)的验收旅程 K。

## 验收条件

- [x] 用已有 F# 插件编译输出组成 ZIP，在管理页预览名称、版本、来源与同 ID 情况，确认后启用并执行真实插件动作。
- [x] 重启后仍可从表中找到受管安装项。重复导入相同包定位到已有行，保留原 ZIP。
- [x] 拒绝越出受管目录的条目、链接、缺少清单或入口的包及内置 ID 冲突。失败显示阶段和可复制原因，不写入包外路径。
- [x] 解包、注册或启用中断后重试，表中只有一项有效安装。已有可用插件及布局保留。

验收记录见[发布版验收](../acceptance.md)。
