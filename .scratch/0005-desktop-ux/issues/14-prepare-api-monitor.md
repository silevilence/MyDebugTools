# 0005-14 — 选好函数和目标再开始监控

Status: ready-for-agent

**What to build:** 让用户从函数来源、已选清单一路走到启动样例或附加到指定进程。

**Blocked by:** 无，可立即开始

对应[桌面体验规格](../spec.md)的验收旅程 E。

## 验收条件

- [x] 分别通过 SDK 搜索和浏览 DLL 选取已有样例函数，查看支持程度、可解码项和已选数量，重复加入有明确状态。
- [x] 搜索无结果时说明当前来源并可清除筛选。无已选函数或无会话时，移除、开始、停止的可用条件与当前状态一致。
- [x] 启动和附加只展示对应输入。用本地 x86、x64 样例覆盖两种入口，核对实际 PID、目标位数及开始后的状态。
- [x] 选错文件或无效 PID 时保留已选函数，可修改后重试。

验收记录见[发布版验收](../acceptance.md)。
