# 0005-16 — 编辑并发送一次 HTTP 请求

Status: ready-for-agent

**What to build:** 按方法、URL、参数及正文的顺序发送请求，就地读懂响应并处理错误。

**Blocked by:** 无，可立即开始

对应[桌面体验规格](../spec.md)的验收旅程 F。

## 验收条件

- [ ] 通过本地回显服务核对常用和自定义方法、路径、查询、请求头和实参。发送中可取消，再次发送可用。
- [ ] 覆盖空正文、原始文本、URL 编码表单、multipart 以及二进制文件。正文模式可直接进入对应字段后返回，文件与混合字段按服务实收内容核对。
- [ ] JSON 格式化出错时保留原文并定位行列。发送完成可见状态、耗时、头和原文，适用时可切换 JSON/XML 格式化或 HTML 静态预览。
- [ ] 能区分空响应、HTTP 错误响应、连接失败、超时及取消。收到延迟响应时保留用户目前正在阅读的页签和焦点。
