# 0005-18 — 在 Dock 中对照输入与结果

Status: ready-for-agent

**What to build:** 在一个工作区对照编辑器和结果，也能找回隐藏的运行中面板。

**Blocked by:** [08](./08-dock-plugin-panels.md)

对应[桌面体验规格](../spec.md)的验收旅程 L、M。

## 验收条件

- [x] 将 HTTP 请求与响应并排或上下停靠，缩窄窗口后可在标签间快速切换。响应标明所属请求。
- [x] 通过本地延迟响应验证完成提示，正在查看的日志、草稿与键盘焦点保留。
- [x] DLL 导出或签名与依赖、调用结果可分栏，并指向相应的文件及函数。关闭再开不重复创建工作状态。
- [x] 隐藏采集中面板后主窗仍显示可点击的采集状态，重新打开能查看同一会话和记录；隐藏过程不停止采集。

验收记录见[发布版验收](../acceptance.md)。
