# 0005-08 — 停靠、浮动与找回真实插件面板

Status: ready-for-agent

**What to build:** 用真实 FuncUI 插件走通停靠与重载，在现有 Avalonia 宿主上决定布局库选型。

**Blocked by:** 无，可立即开始

对应[桌面体验规格](../spec.md)的验收旅程 G、I、L。

## 验收条件

- [x] 基于项目依赖选择候选，在真实插件上验证拖动提示、四边停靠、分隔条、标签合并和排序、浮窗与取消拖动。记录候选版本及实测结论。
- [x] “视图”菜单反映显隐状态，重复打开只聚焦。关闭浮窗或面板后从菜单找回同一草稿，键盘能移动、停靠和关闭。
- [x] 浮动时覆盖编译并重载两次，新界面仅挂载一次，独立页面的草稿仍在，卸载诊断确认旧程序集能回收。
- [x] 提供方停用时浮窗和菜单一起撤下，恢复时可回到原位置。注销已移除插件后，布局中没有失效的入口。

验收记录见[发布版验收](../acceptance.md)。
