# 0005-15 — 持续阅读、筛选和回看采集记录

Status: ready-for-agent

**What to build:** 从现有采集入口产生一段已知记录，按函数或线程查看，停止后还能回到刚才的记录。

**Blocked by:** 无，可立即开始

对应[桌面体验规格](../spec.md)的验收旅程 E、M。

## 验收条件

- [ ] 在记录旁显示所选会话、目标、位数、生效时间、调用数、丢失数与停止操作。用本地样例计数核对实际记录。
- [ ] 筛选时显示匹配数与总数。新记录到达时保留当前记录、详情与阅读位置，清除筛选能回到完整列表。
- [ ] 选一条记录核对线程、栈、入参、返回和耗时。等待、未返回、部分解码和丢失各自可辨。
- [ ] 停止后目标继续运行。插件停用后再启用以及重载后可回看，退出并重启宿主后记录已清除。
