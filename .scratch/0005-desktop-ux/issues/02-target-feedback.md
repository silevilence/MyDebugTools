# 0005-02 — 选择调试目标并反馈错误

Status: ready-for-agent

**What to build:** 选一次 DLL 或进程，把有效对象带到工作台或监控准备页。选择失败时可改正或复制诊断。

**Blocked by:** 无，可立即开始

对应[桌面体验规格](../spec.md)的验收旅程 B、H。

## 验收条件

- [x] 分别用本地 x86、x64 样例核对文件名、进程名或 PID、目标架构和宿主架构。缺运行时时指出所需位数，静态浏览仍可用。
- [x] 空 PID、非数字、进程已退出和文件不存在各有中文原因与下一步。输入或选择取消后，仍能分辨当前有效对象。
- [x] 就地预览并复制包含版本、时间、页面、动作、目标摘要和原始原因的诊断。连续两次出错后从剪贴板读回对应错误，私人路径前缀已处理。
- [x] 模拟剪贴板不可写，界面保留可全选的同一份摘要。键盘焦点可回到出错字段继续编辑。

验收记录见[发布版验收](../acceptance.md)。
