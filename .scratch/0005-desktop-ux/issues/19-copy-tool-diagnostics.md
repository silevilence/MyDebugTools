# 0005-19 — 从各工具复制可用的错误报告

Status: ready-for-agent

**What to build:** 让每种工具的错误和部分失败都能交给维护者，在失败处看到原因、恢复动作与可复制摘要。

**Blocked by:** [02](./02-target-feedback.md)

对应[桌面体验规格](../spec.md)的验收旅程 H。

## 验收条件

- [ ] 用本地数据分别触发插件目录或包错误、签名不完整、缺失依赖、监控目标无效、无效 JSON 和 HTTP 连接失败。每处都有就地提示、下一步和诊断入口。
- [ ] 从系统剪贴板读回报告，核对时间、版本、页面、动作、对象、实际原因及适用的位数、插件、函数、会话或 HTTP 状态。连续失败不会复制到前一次错误。
- [ ] 用合成凭据核对预览、剪贴板与原始异常中的脱敏。凭据、Cookie、查询实参、正文、缓冲区及私人路径前缀不会随摘要带出。
- [ ] 剪贴板不可写时能全选同一份处理过的诊断。复制代码或原文与复制诊断清楚区分，局部失败保留其他可用结果。
