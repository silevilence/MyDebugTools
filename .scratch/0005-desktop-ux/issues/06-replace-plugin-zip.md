# 0005-06 — 更换外部插件版本

Status: ready-for-agent

**What to build:** 加载同 ID 的外部新版前确认替换对象。成功后使用新版，失败后仍可使用旧版。

**Blocked by:** [05](./05-load-plugin-zip.md)

对应[桌面体验规格](../spec.md)的验收旅程 G、K。

## 验收条件

- [x] 用同一插件两个本地构建验证版本与来源预览，取消后旧菜单和操作仍可用。
- [x] 确认替换后仅存在一项安装，新操作只响应一次。重启后仍为新版，其他页面的输入与位置保留。
- [x] 让新版准备或激活失败，显示失败阶段并保留或恢复可用旧版。随后导入有效包可以成功。
- [x] 活动采集沿用继续或先结束的选择。替换成功后卸载诊断能确认旧程序集回收。

验收记录见[发布版验收](../acceptance.md)。
