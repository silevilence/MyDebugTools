# 0005-09 — 保存并恢复工作区布局

Status: ready-for-agent

**What to build:** 重启时找回熟悉的排列，换显示器或布局损坏时仍能操作主工作区。

**Blocked by:** [08](./08-dock-plugin-panels.md)

对应[桌面体验规格](../spec.md)的验收旅程 I、L。

## 验收条件

- [x] 保存并重开一组并排、标签、隐藏与浮动面板，核对尺寸比例、顺序、显隐和浮窗边界。
- [x] 插件暂不可用时仍可启动，重新可用后按稳定标识恢复一次。上次宿主的采集会话不会被布局恢复。
- [x] 移除承载浮窗的显示器后，窗口回到可见区域。损坏的布局回退为可操作的默认布局。
- [x] 在有草稿和运行中任务时恢复默认布局，窗口重排，所编辑内容和任务状态保留。

验收记录见[发布版验收](../acceptance.md)。
