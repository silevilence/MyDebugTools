# 0005-12 — 按可见预览复制和导出代码

Status: ready-for-agent

**What to build:** 为一个调用或一批函数生成互操作代码，让复制和保存的内容与核对过的预览一致。

**Blocked by:** 无，可立即开始

对应[桌面体验规格](../spec.md)的验收旅程 C、M。

## 验收条件

- [ ] 分别验证当前调用示例、批量声明以及三种既有格式，显示选择范围、格式、成功数和跳过数。
- [ ] 修改语言、选择或实参后，预览立即更新或明确提示已过期。读取系统剪贴板并与有效预览及保存文件逐字核对。
- [ ] 单个函数被跳过时列出具体原因，其余成功生成的代码仍能使用。代码与诊断各有明确的复制动作。
- [ ] 复制与保存成功可见，保存显示文件位置。取消保存后预览仍在。
