# 0005-04 — 按界面展开插件关系

Status: ready-for-agent

**What to build:** 从提供界面的插件展开查找菜单与页签扩展，也能切换为按唯一插件列出的平表。

**Blocked by:** [03](./03-plugin-table.md)

对应[桌面体验规格](../spec.md)的验收旅程 G、J。

## 验收条件

- [ ] 从 DLL 工作台找到 DLL 依赖页签。键盘可展开层级，筛选命中子项时可见父项。
- [ ] 一个插件提供页面又扩展多处时，引用指向同一主行。独立、循环、提供方缺失的插件均可找到，计数等于唯一插件数。
- [ ] 兼容旧清单和保存的目录。未启用且无关系声明的插件标为待识别，展示列表期间不执行插件，正常启用后按实际注册校正。
- [ ] 版本失配显示目标、所需及实际版本，仅受影响的扩展撤下。重新兼容后只挂载一次，并保留启用偏好。
