# 0004-05 — 编辑 JSON 与查看响应

Status: ready-for-agent

**What to build:** 编辑和格式化 JSON 请求，按内容类型阅读响应，也可随时查看原文。

**Blocked by:** [0004-03 发送正文与文件](03-request-body-files.md)

## 验收条件

- [ ] 有效 JSON 有语法高亮并可格式化；无效 JSON 保留原文，指出错误位置供用户修正。
- [ ] 返回 JSON/XML 时可切换格式化高亮视图和原文，错误或无效内容仍可从原文核对。
- [ ] 返回 HTML 错误页时显示状态码，可切换静态预览与原文；用本地样例核对预览期间脚本未执行、远程资源未加载。
