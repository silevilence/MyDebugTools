# 0004-04 — 查看请求历史

Status: ready-for-agent

**What to build:** 从请求日志回看每次真实发送的参数与结果，重启后可查历史，并可单独清空日志。

**Blocked by:** [0004-02 保存接口定义](02-save-api-definition.md)

## 验收条件

- [x] 同一接口分别以 1001、1002 发送，再临时发送一次，日志中出现三条独立记录，各自保留当时的实参与结果。
- [x] 重启后能查回最近记录。使用已知测试上限，超限时最旧记录先淘汰，保留顺序正确。正式保留上限的具体数值尚未指定。
- [x] 清空日志后历史为空，原接口定义与默认值仍可打开并用于下一次发送。

实施检查：以测试上限 3 核对三次独立记录、重新读取、第四次淘汰最旧项，以及清空时的在途结果、保留定义和再次发送。正式上限为 100 条。
