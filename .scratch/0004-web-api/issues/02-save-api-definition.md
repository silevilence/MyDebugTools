# 0004-02 — 保存接口定义

Status: ready-for-agent

**What to build:** 在软件内部目录维护可复用的接口定义；发送时可单独填实参，保留原默认值。

**Blocked by:** [0004-01 临时发送请求](01-send-http-request.md)

## 验收条件

- [x] 创建、保存并重新打开接口定义，核对方法、URL、请求头、正文配置和参数定义。参数可描述名称、位置、类型、必填状态、说明及可选默认值。
- [x] 依次用默认值 1001 和临时值 1002 发送，服务收到相应值；重新打开定义仍是 1001，主动编辑保存后默认值才改变。
- [x] 同一接口多次发送后目录仍只有一份定义，另行临时发送也不会新增目录条目。

实施检查：定向回显用例已通过。保存后重读全部字段，发送 1001、1002 和一条临时请求，目录仍只有一项；主动保存后默认值变为 1003。
