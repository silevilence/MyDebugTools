# 0004-03 — 发送正文与文件

Status: ready-for-agent

**What to build:** 在请求编辑器中选择正文类型，发送文本、表单或文件，并从服务回显核对收到的内容。

**Blocked by:** [0004-01 临时发送请求](01-send-http-request.md)

## 验收条件

- [ ] 分别发送空正文、原始 JSON/XML 文本和 URL 编码表单，核对内容类型、文本与编码后的字段值。
- [ ] 一次 multipart 请求同时包含文本和文件，回显服务能分别读到字段值与原文件内容。
- [ ] 发送本地二进制文件，服务收到的字节数和内容与原文件一致。
