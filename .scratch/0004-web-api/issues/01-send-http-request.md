# 0004-01 — 临时发送请求

Status: ready-for-agent

**What to build:** 临时输入方法和 URL，向本地服务发送请求，立即检查原始响应或传输错误。

**Blocked by:** [0000-01 单入口与插件管理](../../0000-plugin-host/issues/01-desktop-entry.md)

## 验收条件

- [ ] 分别使用常用与服务支持的合法自定义方法，核对路径、查询参数、请求头及服务实际收到的值。底层限制可见。
- [ ] 界面显示状态码、耗时、响应头和原文，收到 HTTP 错误状态时仍能查看响应内容。
- [ ] 本地样例分别产生连接失败、超时及主动取消，界面能区分三种结果。
