# 分流标签

角色名直接用作本地实现任务的 `Status:` 值。

| 技能角色 | 本地标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待提出者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，代理可以独立实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 已决定不处理 |
