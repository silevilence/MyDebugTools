# 领域文档

MyDebugTools 使用单一领域上下文。开始探索代码前，先读根目录的 `CONTEXT.md`，再读 `docs/adr/` 中与当前工作有关的架构决策记录（ADR）。

文档尚不存在时，直接继续工作。术语含义或架构决定明确后，由 `domain-modeling` 按需创建相应文档。

任务标题、重构建议、待验证的假设和测试名称都使用 `CONTEXT.md` 定义的术语。遇到未收录的概念，先检查已有术语能否表达；确有缺口时，记下交给 `domain-modeling`。

如果建议与现有 ADR 冲突，指出对应的 ADR 编号和具体冲突，并说明重新讨论该决定的理由。
